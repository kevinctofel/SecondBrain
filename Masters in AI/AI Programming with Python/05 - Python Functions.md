## Python Functions

### Functions

Reusable blocks of code to divide complex tasks into manageable, simple steps. This brings re-usability, organization, and repeatable, standard processes into our programs.

#### User defined functions

Function definition syntax:
```python
def function_name (parameters):
    code block here
```

#### Generators

A special type of Python function that generates values one at a time, only when called, using the _yield_ keyword instead of the _return_keyword. They're extremely memory efficient for handling large amounts of data. A generator "yields" one item at a time and then pauses until the next item is requested.



### Managing exceptions

Exceptions are used to handle unexpected errors in our code so that our program isn't disrupted.
